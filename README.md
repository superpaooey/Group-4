# Activity 2

Student API project built with Node.js and Express.

## Project Structure

```text
.
├── server.js
├── app.test.js
└── src/
    ├── app.js
    ├── config/
    ├── controllers/
    ├── middleware/
    ├── models/
    ├── routes/
    ├── services/
    ├── utils/
    └── validations/
```

## Run the Project

```bash
npm install
npm start
```

The API runs on port 3000 by default.
